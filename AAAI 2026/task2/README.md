# 纸折叠测试数据分析工具

## 功能说明

本工具用于统计分析纸折叠测试的准确率数据，支持处理多种文件格式：

### 支持的文件格式

1. **CSV格式** - 两种不同的CSV格式：
   - 标准格式：直接包含题目数据
   - Task2格式：以`#`开头的元数据行 + 题目数据

2. **XLSX格式** - Excel文件格式
   - 自动读取第一个工作表
   - 支持与CSV相同的数据结构

### 分类统计

按照题目类型进行分类统计：
- **fold_1**: 一次折叠题目
- **fold_2**: 两次折叠题目  
- **other**: 其他类型题目

### 输出文件

1. `complete_test_results.csv` - 包含所有题目的完整测试结果
2. `accuracy_report.csv` - 按类别统计的准确率报告

### 使用方法

```bash
# 安装依赖
npm install xlsx

# 运行分析
node analyze_accuracy.js
```
